# 要件定義書

> `/spec` を実行すると、Claude が `docs/01_customer.md` を読んでここを埋めます。
> 埋まったら `/build` で実装します。

## 0. 画面の型

```tsx
const TONE = "indigo";                        // 士業・不動産・BtoB
const DENSITY = "normal";                     // 同時並行20社前後
const LAYOUT: "queue" | "stage" | "due" = "stage";  // どの段階で止まっているかを見る
const UNIT = "社";                             // 顧客企業を数える単位
const CATEGORIES = ["アポ打診中", "初回ヒアリング", "課題を深掘り", "解決策の提示", "検証の合意"];
```

- **なぜ `stage` か**: 3行目が「顧客ごとの課題・仮説・ヒアリング結果が一覧で見える」。新規事業のヒアリングは、打診 → 初回 → 深掘り → 提示 → 合意 と段階が進むもので、担当者が知りたいのは「どこで止まっているか」だと思われる。
- **なぜ `indigo` か**: 顧客が企業の新規事業部・経営企画部（BtoB）のため。
- **なぜ `normal` か**: 🔮 同時並行20社前後という想定のため、詰めすぎず・空けすぎずの密度。

## 1. このツールが解くこと

顧客ヒアリングの内容が Excel・手元のメモ・Teams に散らばっていて、1社の状況を思い出すのに複数ツールを開いて探し回っている状態を、**1画面で「どの顧客が・どの段階で・何に困っていて・次に何をするか」が見える**状態にする。

## 2. 使う人と、使う場面

- 使う人: 新規事業担当者（企業の新規事業部・経営企画部）
- いつ開くか: ヒアリングの直後（記録するため）と、週のはじめ（止まっている顧客を拾い上げるため）
- 開いて最初にしたいこと: 動きが止まっている顧客を見つけて、次のアクションを決める

## 3. 画面（1つだけ）

左メニューで3画面を切り替える。ルーティングは増やさない。

1. **一覧** — 段階ごとに束ねた顧客一覧＋統計＋検索・絞り込み
2. **新規登録／編集** — 顧客の登録・修正
3. **設定** — 表示名の変更／見本データの入れ直し／全消去

## 4. データ項目

| 項目 | 型 | 必須 | 例 |
|---|---|---|---|
| 顧客・部署 | string | ○ | 北山フーズ 経営企画部 |
| いまの段階 | string（CATEGORIES から選ぶ） | ○ | 課題を深掘り |
| 聞き取った課題 | string | | 拠点ごとに在庫の数え方が違い、集計に3日かかる |
| 次にやること・仮説 | string | | 1拠点だけで数え方を統一できないか打診する |
| 最後に話した日 | date | ○ | 2026-08-19 |

※ 入力する項目は5つまで。これ以上増やすと、その場で登録して試せなくなる。

## 5. 操作（3つまで）

| # | 操作 | 何が起きるか |
|---|---|---|
| 1 | 登録・編集する | 顧客と段階・課題・次にやることを保存し、一覧の該当段階に並ぶ |
| 2 | 段階で束ねて見る／検索・絞り込む | どの段階に何社たまっているかが分かる。顧客名・課題・次にやることから検索できる |
| 3 | 完了にする／削除する | 追いかけ終わった顧客を進行中の一覧から外す |

## 6. やらないこと

- 複数人でのリアルタイム共有・アカウントごとのログイン機能
- 顧客からの直接入力・顧客向けの公開ページ
- ヒアリング内容の自動要約・AI分析などの生成AI機能

## 7. 完成条件

- [ ] 開いた瞬間に「どの段階に何社たまっているか」と「7日以上動きがない件数」が分かる
- [ ] その場で1社登録でき、段階の変更・課題の追記・削除ができる
- [ ] リロードしてもデータが残る（`localStorage`）

## 8. 保存方法

`localStorage` に1つのキーで保存する。キー名: `hearing-records`（表示名は `hearing-appname`）
※ 端末ごとの保存です。複数人での共有は第3回で扱います。

## 9. ダミーデータ

初回表示用に14件。実在の人名・会社名・連絡先は使わない。
進行中9件・完了5件。日付は `ago(n)`（n = 0〜21）で散らす。
